    LeetCode 209 · 长度最小的子数组¶

    难度：中等 ｜ 标签：数组、滑动窗口、前缀和、二分 状态：✅ 已在 LeetCode 跑通（2026-11-17）

    1. 题目¶

    给定一个含有 n 个正整数的数组 nums 和一个正整数 target，找出该数组中满足其和 >= target 的长度最小的连续子数组，返回其长度。不存在则返回 0。

    示例：

    输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 的和为 7，长度最小。

    2. 思路一：滑动窗口（最优，O(n)）¶

    维护一个连续窗口 [l, r]：

    1. 右指针 r 每次扩张，把 nums[r] 加入 sum。
    2. 当 sum >= target 时，记录长度，然后左指针 l 收缩，直到 sum < target。
    3. 全程取最小长度。

    因为数组全是正数，扩张只会增大和、收缩只会减小和，所以 l 不需要回退，每个元素最多进出一次。

    代码¶

    class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();
        int l = 0, sum = 0, ans = INT_MAX;

        for (int r = 0; r < n; ++r) {
            sum += nums[r];

            while (sum >= target) {
                ans = min(ans, r - l + 1);
                sum -= nums[l];
                ++l;
            }
        }
        return ans == INT_MAX ? 0 : ans;
    }
};

    复杂度¶

    • 时间：O(n)，每个元素最多被加入、移除一次
    • 空间：O(1)

    3. 思路二：前缀和 + 二分（O(n log n)）¶

    定义前缀和 prefix[i] = nums[0..i-1] 的和，则区间 [i, j) 的和为：

    prefix[j] - prefix[i] >= target

    移项：

    prefix[j] >= prefix[i] + target

    固定左端点 i，在 prefix[i+1..n] 中二分找第一个 >= prefix[i] + target 的位置 j，长度就是 j - i。

    因为数组是正数，prefix 严格递增，所以可以二分。

    代码¶

    class Solution {
public:
    int minSubArrayLen(int target, vector<int>& nums) {
        int n = nums.size();
        vector<long long> prefix(n + 1, 0);
        for (int i = 0; i < n; ++i) {
            prefix[i + 1] = prefix[i] + nums[i];
        }

        int ans = INT_MAX;
        for (int i = 0; i < n; ++i) {
            long long need = prefix[i] + target;
            auto it = lower_bound(prefix.begin() + i + 1, prefix.end(), need);
            if (it != prefix.end()) {
                int j = it - prefix.begin();
                ans = min(ans, j - i);
            }
        }
        return ans == INT_MAX ? 0 : ans;
    }
};

    复杂度¶

    • 时间：O(n log n)
    • 空间：O(n)

    4. 两种解法对比¶

    解法 时间 空间 前提 建议
    滑动窗口 O(n) O(1) 正数 首选
    前缀和 + 二分 O(n log n) O(n) 前缀单调（非负） 备选/追问

    5. 边界与测试¶

    nums target 输出 说明
    [2,3,1,2,4,3] 7 2 示例
    [1,4,4] 4 1 单元素满足
    [1,1,1,1,1,1,1,1] 11 0 总和不够
    [] 7 0 空数组
    [1,2,3] 3 1 最后一个元素

    6. 易错点¶

    1. 用 if 而不是 while：左指针可能要连续收缩多次。
    2. 长度写成 r - l：应为 r - l + 1。
    3. 先更新再收缩的顺序：最短问题要「合法时先更新，再收缩」。
    4. 前缀和二分起点写成 i：必须从 i + 1 开始，保证窗口非空。
    5. 前缀和用 int：累加可能溢出，用 long long。
    6. 忽略正数前提：有负数时前缀和不单调，二分失效。

    7. 面试表达¶

    这题用滑动窗口最合适：右指针扩张，窗口和 >= target 时记录长度并收缩左指针。因为数组是正数，窗口和关于左右端点单调，所以每个元素最多进出一次，O(n)。如果要求换一种思路，可以用前缀和 + 二分：固定左端点，二分找最小的右端点，复杂度 O(n log n)。
