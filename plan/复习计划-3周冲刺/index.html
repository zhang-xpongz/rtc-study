    复习计划：3 周冲刺 + 1 周模拟（11/12 → 12/9）¶

    前提：10 年经验，不是从零学。目标是 把经验结构化 + 补 3 个短板： ① WebRTC 源码 ② 音频 3A/NetEQ ③ 大规模 + 云原生；同时 算法每天不断。 节奏：3 周集中复习（11/12–12/2），第 4 周开始投递 + 模拟面（12/3–12/9），之后边面边补。

    0. 三条原则¶

    1. 输出驱动：每天必须产出一张图或一段 5 分钟讲解录音。只看不输出 = 没复习。
    2. 二八分配：P0 占 70% 时间，P1 占 25%，P2 占 5%。别在 AV1、AI 上耗时间。
    3. 先诊断后复习：11/12 先做 30 题自测（见第 8 节），会的直接跳过，只补「半会/不会」。

    1. 每日节奏（全职 6 小时）¶

    时段 内容 说明
    09:00–11:30 专题 A（2.5h） 当天主主题，看 + 写
    14:00–16:00 专题 B / 源码（2h） 源码或第二主题
    16:00–17:30 算法（1.5h） 2 道中等题，限时
    20:00–20:30 输出（0.5h） 画图 / 写笔记 / 录音讲解

    每周留半天缓冲，用来补没消化的内容，不要排满。

    2. 第 1 周（11/12–11/18）：基础 + 传输¶

    天 主题 具体内容 输出
    D1 诊断 + 音视频基础 30 题自测；采样/量化/编码/封装；PTS/DTS/GOP；色彩空间 薄弱清单
    D2 H.264 / H.265 帧类型（I/P/B）、IDR、SPS/PPS、码控（CBR/VBR/ABR）、H.265 改进点 一张编码参数决策图
    D3 FFmpeg 架构（demux/decode/filter/encode/mux）、时间基、转码流程、硬编接入 一条转码命令的参数解释
    D4 RTP / RTCP RFC 3550；SR/RR/SDES/BYE；NACK/PLI/FIR；RTCP 扩展（TWCC） RTP 头字段图
    D5 拥塞控制 + 弱网 GCC 延迟/丢包双控制器；TWCC vs REMB；FEC vs NACK；抖动缓冲 GCC 控制环图
    D6 音画同步 + C++ 并发 RTCP SR 对齐 NTP/RTP；Audio is Master；线程池/无锁队列/内存序 手写线程池
    D7 周测 + 复盘 20 题自测；白板讲「一帧数据从采集到播放」 讲解录音 10 分钟

    本周验收：能不看资料讲清「一帧视频从摄像头到播放器」的全链路，并指出每一段可能丢帧/延迟的点。

    3. 第 2 周（11/19–11/25）：WebRTC + 音频（最关键的短板）¶

    天 主题 具体内容 输出
    D1 WebRTC 架构 + 连接建立 PeerConnection、SDP Offer/Answer、Bundle、a=setup、DTLS-SRTP 连接建立时序图
    D2 ICE / STUN / TURN Candidate 类型（host/srflx/relay）、连通性检查、TURN 中继 NAT 穿透决策树
    D3 jitter buffer + NetEQ 抖动缓冲自适应、丢包隐藏（PLC）、变速播放、音画同步 jitter buffer 状态机
    D4 音频 3A + 编解码 AEC（自适应滤波/双讲）、ANS（谱减/深度学习）、AGC、VAD；Opus/AAC 3A 处理链路图
    D5 Simulcast / SVC + SFU 调度 多流编码 vs 分层编码；切流、丢层、关键帧请求（PLI/FIR） Simulcast vs SVC 对比表
    D6 端到端弱网方案 采集→编码→传输→解码→渲染，每段抗弱网手段；降级策略 弱网决策树
    D7 周测 + 复盘 20 题；白板讲「WebRTC 如何建立连接并抗弱网」 讲解录音 15 分钟

    源码阅读路径（按顺序，别贪多） 1. pc/peer_connection + pc/sdp_offer_answer：连接建立 2. p2p/base/：ICE、Candidate、连接检查 3. modules/congestion_controller/goog_cc/：GCC 4. modules/congestion_controller/rtp/transport_feedback：TWCC 5. modules/video_coding/jitter_buffer：视频抖动缓冲 6. modules/audio_coding/neteq/：音频抖动缓冲与 PLC 7. modules/audio_processing/aec3/、ns/、agc/：3A

    本周验收：能讲清「GCC 如何估带宽、TWCC 为什么把计算搬到发送端、NetEQ 如何对抗抖动、AEC 双讲怎么处理」。

    4. 第 3 周（11/26–12/2）：媒体服务 + 大规模 + 设备 + 端侧¶

    天 主题 具体内容 输出
    D1 SFU / MCU / 混流 / 级联 转发 vs 混流；大小流；级联拓扑；热点房间 SFU 集群架构图
    D2 录制 / 转推 / 存储 单流/合流录制；RTP→RTMP；切片与回放；时间戳对齐 录制链路图
    D3 大规模 + 云原生 负载均衡、就近接入、容灾、K8s、可观测（QoE 指标） 10 万并发架构图
    D4 设备协议 GB28181 信令（REGISTER/INVITE/BYE）、ONVIF Profile、RTSP 交互、私有协议 GB28181 时序图
    D5 端侧 硬编/软编、渲染、功耗、机型适配（君正/瑞芯微/安凯）、4G 弱网 端侧管线图
    D6 系统设计 挑 3 题写一页纸：10 万并发 RTC、IPC 接入网关、录制系统 3 页设计稿
    D7 模拟面 找前同事对练 1 小时；或自录 3 个问题 复盘文档

    本周验收：能白板设计「百万设备接入 + 数十万并发观看」的系统，讲清接入层、调度层、媒体层、存储层和瓶颈。

    5. 第 4 周（12/3–12/9）：投递 + 模拟 + 补漏¶

    事项 目标
    投递 北京清单 S 档 12 家 + 好未来回流，全部走内推
    模拟面 2 场（技术面 + 系统设计面），找前同事或猎头安排

    系统设计 7 题全部写成一页纸
    补漏 按模拟面反馈，回补 2 个最弱模块

    6. 资源清单¶

    协议 / 标准 - RFC 3550（RTP/RTCP）、RFC 4585（AVPF/NACK/PLI）、RFC 5104（FIR）、RFC 6902（TWCC）、RFC 6184（H.264 RTP） - GB/T 28181 标准文本；ONVIF Profile S/G/T 文档

    WebRTC - 源码：https://webrtc.googlesource.com/src - 《WebRTC 权威指南》 - 关键帧 音视频面试题集锦（nxrte.com 连载）

    编解码 / 媒体 - 《音视频开发进阶指南》 - FFmpeg 官方文档 + ffmpeg -h - H.264 白皮书（ITU-T H.264）

    架构 / 实战 - 声网、即构、火山引擎 RTC 技术博客 - 《大规模分布式存储系统》（选读，补云原生）

    算法 - LeetCode Hot 100；剑指 Offer - 手写：线程池、无锁队列、LRU、生产者消费者、单例、智能指针

    7. 7 张必画图（面试可直接用）¶

    1. 一帧数据全链路（采集→编码→RTP→网络→jitter buffer→解码→渲染）
    2. GCC / TWCC 控制环
    3. WebRTC 连接建立时序（SDP → ICE → DTLS → SRTP）
    4. SFU 集群与级联架构
    5. 弱网决策树（什么情况用 FEC、什么情况用 NACK、什么时候降码率）
    6. GB28181 信令流程
    7. 百万设备接入 + 数十万并发架构（结合你的积加 + 好未来经历）

    8. 自测 30 题（11/12 先做，标记 会 / 半 / 不会）¶

    基础（1–6） 1. PTS 和 DTS 的区别？B 帧为什么需要重排？ 2. GOP 太长/太短各有什么问题？ 3. CBR 和 VBR 分别适合什么场景？ 4. YUV 4:2:0 为什么能省一半带宽？ 5. AAC 和 Opus 的差异与选型？ 6. 封装格式 MP4/TS/FLV 的区别？

    传输（7–12） 7. RTP 头里 SSRC、序列号、时间戳各解决什么问题？ 8. RTCP SR 如何实现音画同步？ 9. NACK、PLI、FIR 分别什么时候触发？ 10. GCC 的延迟控制器怎么判断拥塞？ 11. TWCC 相比 REMB 改了什么？ 12. FEC 和 NACK 怎么选？

    WebRTC（13–18） 13. Offer/Answer 里 a=setup 的作用？ 14. ICE 的 candidate 有哪几种？什么时候用 TURN？ 15. DTLS-SRTP 的密钥怎么来？ 16. Simulcast 和 SVC 的本质区别？ 17. jitter buffer 太大/太小分别有什么后果？ 18. NetEQ 的 PLC 是什么？

    音频（19–21） 19. AEC 的双讲检测为什么难？ 20. ANS 的谱减法和深度学习各有什么优劣？ 21. AGC 的目标增益怎么定？

    媒体服务（22–26） 22. SFU 和 MCU 的取舍？ 23. 级联解决什么问题？代价是什么？ 24. 合流录制和单流录制的区别？ 25. RTP 转 RTMP 要注意什么？ 26. 单机并发上不去，怎么定位瓶颈？

    设备 / 端侧（27–30） 27. GB28181 的 REGISTER 和 INVITE 流程？ 28. ONVIF Profile S 和 T 的差异？ 29. 128 路 NVR 的资源怎么调度？ 30. 低功耗 4G 相机怎么省流量和电？

    10. 三个专项补强（穿插进行）¶

    10.1 WebRTC 源码（每天 1 小时，第 2 周集中）¶

    • 不追求通读，按「连接 → 拥塞 → 抖动 → 音频」四条线走
    • 每个模块只回答三个问题：输入是什么、输出是什么、关键数据结构是什么

    10.2 音频 3A（第 2 周 D4 + 之后每天 30 分钟）¶

    • 先懂原理（AEC 自适应滤波、双讲；ANS 谱减；AGC 增益）
    • 再看 WebRTC 实现（aec3/ns/agc 目录）
    • 最后能讲「回声是怎么产生的、怎么消、为什么消不干净」

    10.3 算法（每天 1.5 小时，雷打不动）¶

    • 前 2 周：数组/字符串/链表/栈队列/哈希（Hot 100 前 50）
    • 第 3 周：二叉树/DP/回溯/堆（Hot 100 后 50）
    • 每道题限时 25 分钟，超时看题解，第二天重做
