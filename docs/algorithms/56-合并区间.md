# LeetCode 56 · 合并区间

> 难度：中等 ｜ 标签：数组、排序
> 状态：✅ 已在 LeetCode 跑通（2026-11-17）

## 1. 题目

以数组 `intervals` 表示若干区间的集合，其中单个区间为 `[start, end]`。请合并所有重叠的区间，并返回一个不重叠的区间数组，恰好覆盖输入中的所有区间。

示例：

```
输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：[1,3] 和 [2,6] 重叠，合并为 [1,6]。
```

## 2. 思路：排序 + 一次扫描

1. 按区间**左端点**升序排序。
2. 维护结果数组 `ans`。
3. 遍历每个区间 `cur`：
   - 如果 `ans` 为空，或 `cur[0] > ans.back()[1]`（不重叠），直接加入。
   - 否则与最后一个区间重叠，更新 `ans.back()[1] = max(ans.back()[1], cur[1])`。

排序后，可能重叠的区间一定相邻，所以一次扫描即可。

### 代码

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        if (intervals.empty()) return {};

        sort(intervals.begin(), intervals.end(),
             [](const vector<int>& a, const vector<int>& b) {
                 return a[0] < b[0];
             });

        vector<vector<int>> ans;
        for (const auto& cur : intervals) {
            if (ans.empty() || cur[0] > ans.back()[1]) {
                ans.push_back(cur);                 // 不重叠，开新区间
            } else {
                ans.back()[1] = max(ans.back()[1], cur[1]);  // 重叠，合并
            }
        }
        return ans;
    }
};
```

## 3. 正确性说明

- 排序后，若 `cur` 与之前的某个区间重叠，它一定与 `ans.back()` 重叠或相邻，因为 `ans.back()` 的右端点已经是已处理区间的最大值。
- `cur[0] > ans.back()[1]` 说明 `cur` 完全在最后一个区间右侧，不可能再与更早的区间重叠，可以安全开新区间。
- 合并时取 `max`，处理「当前区间被最后一个区间包含」的情况。

## 4. 复杂度

- 时间：排序 O(n log n)，扫描 O(n) → **O(n log n)**
- 空间：排序栈空间 O(log n)；结果数组 O(n)

## 5. 边界与测试

| `intervals` | 输出 | 说明 |
|---|---|---|
| `[[1,3],[2,6],[8,10],[15,18]]` | `[[1,6],[8,10],[15,18]]` | 示例 |
| `[[1,4],[4,5]]` | `[[1,5]]` | 端点相接也算重叠 |
| `[[1,4],[0,4]]` | `[[0,4]]` | 排序后合并 |
| `[]` | `[]` | 空输入 |
| `[[1,2]]` | `[[1,2]]` | 单区间 |
| `[[1,4],[2,3]]` | `[[1,4]]` | 被包含 |

## 6. 易错点

1. **判断写成 `>=`**：`cur[0] == ans.back()[1]` 时应合并，所以用 `>` 判断「不重叠」。
2. **合并时直接覆盖右端点**：应取 `max`，否则 `[1,4]` 遇到 `[2,3]` 会变成 `[1,3]`。
3. **忘记空输入**：`intervals.empty()` 要直接返回。
4. **排序比较器写错**：只按左端点排序即可；左端点相同按右端点也无妨。
5. **以为要两两比较**：排序后只需和 `ans.back()` 比较。

## 7. 面试表达

> 先按左端点排序，然后一次扫描。用结果数组的最后一个区间和当前区间比较：如果当前左端点大于最后一个区间的右端点，说明不重叠，直接加入；否则合并，右端点取两者的最大值。排序 O(n log n)，扫描 O(n)，总复杂度 O(n log n)。
