# 补充：心理声学（Psychoacoustics）

> 配套 D1「音频基础」第 1.3 节。
> 一句话：**心理声学回答「哪些声音人耳听不见」，编码器据此丢掉「听不见的信息」——这叫去除无关性（irrelevance），区别于去除冗余（redundancy）。**

## 0. 术语表（先读这里）

下面的概念按「物理量 → 主观量 → 分析工具 → 编码工具」排列。正文里再出现时，默认你已看过这里。

### 0.1 物理量（客观、可测量）

| 术语 | 英文 | 含义 | 单位/量级 |
|---|---|---|---|
| 声压 | sound pressure | 声波引起的空气压强变化 | 帕斯卡 Pa；人耳可听范围约 20 µPa – 20 Pa |
| 声压级 | SPL, sound pressure level | 声压相对参考值的对数表示，`20·log10(p/p0)`，p0 = 20 µPa | dB SPL；0 dB 是 1 kHz 的听阈，120 dB 接近痛阈 |
| 频率 | frequency | 每秒振动次数 | Hz；人耳约 20 Hz – 20 kHz |
| 带宽 | bandwidth | 一段频率的范围 | Hz；临界频带低频约 100 Hz |
| 量化噪声 | quantization noise | 量化误差等效成的噪声 | 与量化位数、信号幅度有关 |

| 术语 | 英文 | 含义 | 单位/量级 |
|---|---|---|---|
| 响度 | loudness | 人耳主观感受到的「有多响」 | 线性量，用 sone 表示 |
| 响度级 | loudness level | 以 1 kHz 纯音为基准的等效声压级 | phon；40 phon = 1 sone |

| 痛阈 | threshold of pain | 引起疼痛的声压级 | 约 120 dB SPL |

| 术语 | 英文 | 含义 | 单位/量级 |

## 1. 听觉系统与听觉范围

### 1.1 声音到达大脑的路径

```
声波 → 耳廓（定向）→ 耳道（共振，2–5 kHz 增益）→ 鼓膜 → 听小骨（阻抗匹配）
     → 耳蜗（基底膜按频率分布）→ 毛细胞（机械→电信号）→ 听神经 → 大脑
```

关键点：

- **耳道共振**让 2–5 kHz 最敏感，这也是等响曲线在 3 kHz 附近下凹的原因。
- **基底膜**从蜗底（高频）到蜗顶（低频）按频率排列，是「频率分析器」的物理基础。
- **毛细胞**受损不可再生，噪声性耳聋通常先在 4 kHz 出现「切迹」。

### 1.2 听觉范围

| 维度 | 范围 |
|---|---|
| 频率 | 约 20 Hz – 20 kHz（随年龄下降，成年人多到 15–17 kHz） |
| 声压级 | 0 dB SPL（听阈）– 120 dB SPL（痛阈） |
| 动态范围 | 约 120 dB |

> 注意：0 dB SPL 不是「没有声音」，而是 1 kHz 附近健康年轻人刚好能听到的声压（约 20 µPa）。

## 2. 响度：等响曲线与 phon/sone

### 2.1 等响曲线

人耳对不同频率的敏感度不同。**等响曲线**描述「听起来一样响」的频率-声压组合：

- 1 kHz 处 40 dB SPL 的声音 = 40 phon
- 100 Hz 要听起来和它一样响，需要更高的声压（约 50–60 dB）
- 3–4 kHz 处需要的声压最低（耳道共振）

经典的 Fletcher-Munson 曲线是 1933 年的，ISO 226:2003 是现行标准版本。

### 2.2 phon 与 sone

- **phon（方）**：以 1 kHz 为基准的响度级，等于该声音听起来和 1 kHz 纯音一样响时的 dB 数。
- **sone（宋）**：线性响度单位。40 phon = 1 sone；**响度每翻一倍，约增加 10 phon**。

```
sone ≈ 2^((phon − 40) / 10)
```

例：50 phon ≈ 2 sone，60 phon ≈ 4 sone。

### 2.3 A 计权

A-weighting 是模拟 40 phon 等响曲线的频率加权，用于噪声测量（dB(A)）。它压低低频和高频，突出 1–4 kHz。环境噪声标准基本都用 dB(A)。

### 2.4 三个容易混的维度：强弱、高低、响轻

音频可以从三个物理轴看：**时间、频率、幅度**；对应到主观感知是：**节奏/时值、音高、响度**。

| 说法 | 属于哪个维度 | 客观/主观 | 度量 |
|---|---|---|---|
| 强音 / 弱音 | **幅度（能量）** | 客观 | 声压级 dB SPL、能量 |
| 响 / 轻 | **响度** | 主观 | phon、sone |
| 低频 / 高频 | **频率** | 客观 | Hz |
| 低音 / 高音（音高） | **音高** | 主观 | mel、Bark |

关键点：

1. **「强/弱」是幅度，不是响度**。强音 = 声压级高、能量大的声音；弱音 = 声压级低、接近听阈的声音。
2. **「响/轻」才是主观感受**。同样 60 dB SPL，1 kHz 听起来比 100 Hz 响（等响曲线）。
3. **「低频/高频」是频率轴**，和强弱是两个独立维度。一个高频音可以很弱，一个低频音也可以很强。
4. **频率和音高不是一一对应**：频率越高音高越高，但音高还受声压级、时长影响（Stevens 效应）。

在掩蔽里这两个维度同时起作用：

- **强度**决定掩蔽范围：掩蔽者越强，掩蔽阈值抬得越高、范围越宽。
- **频率距离**决定掩蔽强弱：越靠近掩蔽者，被掩蔽得越厉害。
- **方向不对称**：低频掩蔽高频（向上掩蔽）强于高频掩蔽低频。

举例：

- 1 kHz、80 dB 的强音，会把 1.1 kHz 附近约 30 dB 的弱音掩蔽掉。
- 同样是 80 dB 的 1 kHz 强音，对 100 Hz 的弱音掩蔽效果就弱得多（向下掩蔽弱）。

> 面试时如果说「高频对低频有掩蔽作用」，会被认为方向搞反了。正确说法是「低频对高频的向上掩蔽更强」。

### 2.5 映射关系：强弱→响轻、频率→音高

#### 2.5.1 强弱 → 响轻（幅度 → 响度）

**不是线性对应**，而是两条曲线叠加：

1. **对数压缩**：声压级每 +10 dB，主观响度约翻倍（中等响度、中频纯音）。
2. **频率加权**：同样的声压级，不同频率听起来响度不同（等响曲线）。

常用的两个单位：

- **phon（响度级）**：以 1 kHz 为基准。1 kHz、60 dB 的声音 = 60 phon。
- **sone（响度）**：线性刻度。`sone ≈ 2^((phon − 40) / 10)`。

对照表：

| 响度级 | 响度 | 主观感受 |
|---|---|---|
| 40 phon | 1 sone | 安静房间的轻声 |
| 50 phon | 2 sone | 翻倍 |
| 60 phon | 4 sone | 正常交谈 |
| 70 phon | 8 sone | 吵闹 |
| 80 phon | 16 sone | 很吵 |
| 90 phon | 32 sone | 接近痛阈 |

同一个 SPL 在不同频率的响度不同，例如：

| 声音 | 声压级 | 听起来约等于 |
|---|---|---|
| 1 kHz 纯音 | 60 dB | 60 phon |
| 100 Hz 纯音 | 60 dB | 约 50 phon（更轻） |
| 3 kHz 纯音 | 60 dB | 约 62–65 phon（更响） |

> 这就是为什么音量滑块要用对数刻度、响度归一化要用 LUFS 而不是峰值 dBFS。

另外三个影响因素：

- **时长**：短于约 100–200 ms 的声音，响度会打折（时间积分）。
- **带宽**：同样 SPL，宽带噪声比窄带纯音更响（多个临界带能量叠加）。
- **双耳**：双耳听比单耳响约 6–10 dB。

#### 2.5.2 频率 → 音高（Hz → pitch）

**近似对数**，但不是严格一一对应。

- 音乐里「八度」= 频率 ×2，所以音高与频率的对数成正比。
- 常用的感知刻度是 **mel**：

```
mel(f) = 2595 × log10(1 + f / 700)
```

  - 1 kHz ≈ 1000 mel
  - 2 kHz ≈ 1521 mel（不是 2000）

- **频率分辨力（JND）**：中频约 0.5–1%（1 kHz 时约 5–10 Hz）；低频更敏感，约 1–3 Hz。

音高还受这些因素影响：

| 因素 | 影响 |
|---|---|
| 声压级 | Stevens 效应：低频音在响度提高时音高略升，高频略降（幅度通常小于半音） |
| 时长 | 短于约 50 ms 的声音，音高变得模糊 |
| 波形复杂度 | 复合音的基频可能缺失，人耳仍能「补」出音高（missing fundamental） |
| 年龄/听力 | 高频听力下降会影响高频音高判断 |

**「低音/高音」的两种用法**（容易混）：

| 说法 | 实际含义 | 维度 |
|---|---|---|
| 低音 / 高音 | 音高（pitch） | 感知 |
| 低音 / 高音 | 低频 / 高频成分（bass/treble） | 物理频率 |
| 低频 / 高频 | Hz | 物理 |

> 日常说「这首歌低音很重」通常指低频能量多（bass），不是音高低；说「高音上不去」通常指音高（pitch）。面试时要说清楚是**频率**还是**音高**。

#### 2.5.3 一句话总结

> 强弱是幅度、响轻是响度，两者是对数关系（+10 dB ≈ 2 倍响度），且受频率加权影响；频率是物理量、音高是感知量，两者近似对数（八度=×2），但还受声压级、时长、波形影响。

## 3. 临界频带：耳朵的「滤波器组」

### 3.1 什么是临界频带

基底膜不是逐 Hz 分析，而是分成若干段，每段内的频率成分会互相掩蔽。这个带宽叫**临界频带（critical band）**。

- 数量：约 **24 个 Bark 带**（也有 25 带的说法）
- 带宽：低频约 100 Hz 固定；高频约为中心频率的 20%
- 1 kHz 附近约 160 Hz 宽

### 3.2 常用换算

**Bark 刻度**（Traunmüller）：

```
z(f) = 26.81 × f / (1960 + f) − 0.53      （f 单位 Hz，z 单位 Bark）
```

1 kHz ≈ 8.5 Bark；20 kHz ≈ 24 Bark。

**ERB（等效矩形带宽）**：

```
ERB(f) = 24.7 × (4.37 × f / 1000 + 1)     （Hz）
```

### 3.3 为什么编码器要用临界频带

- 量化噪声落在「同一个临界带」内才会掩蔽信号；跨带掩蔽很弱。
- 所以编码器**按临界带（或近似它的 scalefactor band）分组**，每组单独算掩蔽阈值、分配比特。
- AAC 的 scalefactor band、MP3 的 scalefactor band 都是临界带的工程近似。

## 4. 掩蔽效应：心理声学的核心

### 4.1 频域掩蔽（同时掩蔽）

一个强音（掩蔽者）会让邻近频率的弱音（被掩蔽者）听不见。

- **不对称**：**向上掩蔽强于向下掩蔽**。1 kHz 的强音更容易盖住 1.5 kHz 的弱音，而不是 500 Hz 的。
- 掩蔽阈值随频率距离衰减，通常用「扩展函数（spreading function）」建模。
- 掩蔽者越强，掩蔽范围越宽。

### 4.2 时域掩蔽

| 类型 | 时间范围 | 说明 |
|---|---|---|
| 前掩蔽（pre-masking） | 掩蔽者之前约 5–20 ms | 大脑处理延迟导致 |
| 后掩蔽（post-masking） | 掩蔽者之后约 50–200 ms | 听觉神经的残留效应 |

工程上主要利用**后掩蔽**：瞬态之后的一小段噪声可以放宽。

### 4.3 双耳掩蔽级差（BMLD）

当信号与掩蔽者相位不同（例如一个耳朵反相），掩蔽阈值能降低约 **10–15 dB**。这是双耳听觉的空间分离能力，属于「鸡尾酒会效应」的一部分。

### 4.4 掩蔽的工程意义

- 强音附近的弱音可以直接**不编码**（省比特）。
- 量化噪声只要**低于掩蔽阈值**就听不见，不需要追求「无噪声」。
- 这就是有损压缩「听起来无损」的根本原因。

## 5. 绝对听阈与 SMR

### 5.1 绝对听阈（ATH）

在安静环境下，人耳刚能听到的各频率声压级：

| 频率 | 约听阈 |
|---|---|
| 20 Hz | 70–80 dB |
| 100 Hz | 25–30 dB |
| 1 kHz | 3 dB 左右 |
| 3–4 kHz | 最低（约 −5–0 dB） |
| 15 kHz | 10–20 dB |

低频听阈高，是因为耳道和鼓膜对低频不敏感；这也是为什么低频可以容忍更大的量化噪声。

### 5.2 SMR（信掩比）

```
SMR(dB) = 信号能量(dB) − 掩蔽阈值(dB)
```

- SMR 越大，说明这个频带的信号越「突出」，越需要精度。
- 编码器把比特优先分配给 SMR 大的频带。
- 量化噪声必须压到掩蔽阈值以下：`噪声 < 信号 − SMR`。

### 5.3 心理声学模型的计算步骤

以 MPEG 模型为例：

1. **频谱分析**：FFT（MP3 模型 1 用 512/1024 点；AAC 用 MDCT）
2. **归一化到 SPL**：按声压级换算
3. **加绝对听阈**：低于 ATH 的成分直接忽略
4. **区分 tonal / noise**：局部极大值判为音调成分，其余为噪声
5. **计算掩蔽**：对每个掩蔽者应用扩展函数，叠加得到全局掩蔽阈值
6. **按临界带汇总**：每个带一个阈值
7. **算 SMR**：信号能量与阈值之差
8. **比特分配**：SMR 大的带分更多比特，使量化噪声低于阈值

## 6. 编码器怎么用这些结论

### 6.1 MP3

- 多相滤波器组 + MDCT，576 个频点
- 心理声学模型 1/2 计算掩蔽阈值
- **比特池（bit reservoir）**：允许当前帧借用前后帧的比特，应对瞬态
-  scalefactor 调整每个带的量化步长

### 6.2 AAC

- MDCT，长块 2048 点 / 短块 256 点，50% 重叠
- **块切换**：检测到瞬态时切短块，抑制预回声
- **TNS**（时域噪声整形）：把量化噪声在时间上「整形」，压到掩蔽区
- **PNS**（感知噪声替换）：噪声类信号只传能量，不传波形
- M/S 立体声、强度立体声：利用声道间相关性（这属于冗余去除）

### 6.3 预回声（pre-echo）

瞬态（如鼓声）之前如果量化噪声扩散，会听到「提前的嘶声」。

原因：MDCT 是整块变换，量化误差在整块内均匀分布，瞬态前的静音段就会暴露噪声。

解决：

1. **短块**（AAC 的 256 点）——时间分辨率高，噪声集中在瞬态附近
2. **TNS**——频域做时间包络整形
3. **比特池/比特预留**——给瞬态帧更多比特

### 6.4 Opus

- **SILK**：语音编码，LPC + 基音预测，支持 8/12/16 kHz（NB/MB/WB）
- **CELT**：MDCT，低延迟（帧长 2.5–20 ms），适合音乐和全频带
- **Hybrid**：两者结合，中高码率语音，支持 24 kHz（SWB）
- 内部固定 48 kHz，支持 6–510 kbps、DTX、FEC、PLC

Opus 的比特分配同样基于感知掩蔽（CELT 使用掩蔽曲线做频带比特分配），但实现细节与 MP3/AAC 不同。

#### 6.4.1 这四个词分别是什么意思

**① 内部固定 48 kHz**

- 指 Opus **内部处理和编码的采样率固定为 48 kHz**，不是「只能编码 48 kHz 的音频」。
- 输入可以是 8/12/16/24/48 kHz，编码器内部统一重采样到 48 kHz 再编码。
- RTP 的时钟频率固定 **48000 Hz**，SDP 里写 `a=rtpmap:111 opus/48000/2`。
- 编码带宽是另一回事：NB（4 kHz）、WB（8 kHz）、SWB（12 kHz）、FB（20 kHz），由编码器按码率/内容选择。
- 好处：一套算法覆盖所有输入采样率，RTP 时钟统一；代价：低采样率输入要上采样，有少量开销。

**② 6–510 kbps**

- 码率范围：**6 kbps**（窄带单声道语音，极端弱网）到 **510 kbps**（全带宽立体声）。
- WebRTC 语音常用 16–64 kbps，音乐 64–128 kbps。
- 这个范围不是「随便选一个固定值」，而是可以**逐帧调整**（TOC 自描述 + `OPUS_SET_BITRATE`）。

**③ DTX（Discontinuous Transmission，不连续发送）**

- 发送端用 VAD 检测静音，静音期间**停止发音频包**，只周期性发送舒适噪声（CN）参数。
- 收益：省带宽、省电；接收端用 CNG 生成背景噪声，避免「死寂」。
- 代价：VAD 误判会切掉语音开头/结尾；音乐场景不适用。
- WebRTC 开关：SDP `usedtx=1`。

**④ FEC（Forward Error Correction，前向纠错）**

- Opus 的带内 FEC 是 **SILK 层的 LBRR**（Low Bit-Rate Redundancy）：在当前帧里嵌入**前一帧的低码率副本**。
- 丢包时，解码器可以用它**近似恢复前一帧**（不是精确恢复）。
- 限制：只能在 SILK / Hybrid 模式用（CELT-only 没有）；只能恢复**前一帧**；恢复质量低于原帧。
- 代价：额外码率（通常 10–30%）。
- WebRTC 开关：SDP `useinbandfec=1`。
- 注意：它与传输层的 ULPFEC / FlexFEC 是两回事，后者与编码器无关，可精确恢复整包。

**⑤ PLC（Packet Loss Concealment，丢包隐藏）**

- 解码器在丢包、且 FEC/NACK 都没救回来时，用**前一帧外推**（基音重复、渐变淡出）生成替代音频。
- 作用：避免爆音、断音；连续丢包会出现机械音、失真。
- 与 jitter buffer 配合：先等 NACK 重传，超时后再 PLC。

#### 6.4.2 一次丢包的处理顺序

```
发送端：VAD 判断静音 → DTX（不发） / 正常编码（可带 LBRR 冗余）
   │
网络：丢包
   │
接收端：NACK 重传（若开启）→ 带内 FEC（LBRR）→ 仍缺失 → PLC → 播放
```

| 机制 | 端 | 解决什么 | 代价 | WebRTC 开关 |
|---|---|---|---|---|
| DTX | 发送 | 静音不占带宽 | VAD 误判 | `usedtx=1` |
| FEC（LBRR） | 发送 | 恢复前一帧 | 10–30% 冗余码率 | `useinbandfec=1` |
| NACK | 接收反馈 | 精确重传丢失包 | RTT 延迟 | 默认开启 |
| PLC | 接收 | 掩盖无法恢复的丢包 | 音质下降 | 解码器内置 |
| jitter buffer | 接收 | 吸收网络抖动 | 增加延迟 | 由接收端策略控制 |

## 8. 面试问答（10 题）

**Q1：为什么 MP3 128 kbps 听起来接近 CD？**
A：利用了心理声学。CD 是 1.4 Mbps 的 PCM，MP3 去掉了两类信息：冗余（声道间相关、周期性）和无关（被掩蔽的弱音）。量化噪声被压到掩蔽阈值以下，所以听感接近。

**Q2：什么是临界频带？为什么编码器要按它分组？**
A：基底膜的频率分析单元，约 24 个 Bark 带。掩蔽主要发生在同一临界带内，所以按带计算掩蔽阈值、分配比特才准确。AAC/MP3 的 scalefactor band 就是它的近似。

**Q3：频域掩蔽为什么不对称？**
A：基底膜的行波向蜗顶传播，低频掩蔽高频（向上掩蔽）更容易；高频要掩蔽低频很难。工程上用扩展函数建模，向上掩蔽的斜率更平缓。

**Q4：前掩蔽和后掩蔽的时间范围？**
A：前掩蔽约 5–20 ms，后掩蔽约 50–200 ms。编码器主要利用后掩蔽放宽瞬态后的量化精度。

**Q5：什么是预回声？怎么解决？**
A：瞬态前的量化噪声暴露。用短块（提高时间分辨率）、TNS（时域噪声整形）、比特池（给瞬态帧更多比特）解决。

**Q6：SMR 是什么？**
A：信掩比，信号能量与掩蔽阈值之差。SMR 越大越需要精度，编码器据此分配比特。

**Q7：为什么低频可以容忍更大的量化噪声？**
A：低频的绝对听阈高（20 Hz 要 70–80 dB 才听得到），且低频临界带宽窄、掩蔽阈值高，所以噪声不容易被察觉。

**Q8：phon 和 sone 的区别？**
A：phon 是响度级（以 1 kHz 为基准），sone 是线性响度。40 phon = 1 sone，每增加 10 phon 响度约翻倍。

**Q9：A 计权是什么？**
A：模拟 40 phon 等响曲线的频率加权，用于噪声测量，突出 1–4 kHz，压低低频。

**Q10：Opus 为什么适合 WebRTC？**
A：低延迟（2.5–20 ms 帧）、宽码率范围（6–510 kbps）、内置 FEC/DTX/PLC、内部 48 kHz 与 RTP 时钟一致，且 SILK/CELT 混合能兼顾语音和音乐。

## 9. 常见误区

| 误区 | 事实 |
|---|---|
| 「有损压缩就是删数据」 | 是删「感知上无关」的数据，不是随机删 |
| 「码率越高一定越好」 | 超过透明阈值后听感提升很小，且受端到端延迟/网络影响 |
| 「心理声学只用于音乐」 | 语音编码（SILK/AMR）也用，只是模型不同 |
| 「掩蔽阈值是固定值」 | 随掩蔽者频率、强度、时间动态变化 |
| 「A 计权等于响度」 | A 计权是近似，真正响度要用 LUFS/等响模型 |
