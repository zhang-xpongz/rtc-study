# 写作约定（学习资料）

> 目的：让每份资料「先能读懂，再能深入」。约定从 2026-11-13 起执行。

## 1. 文档结构

```
0. 术语表（先读这里）
1. 背景：这个知识解决什么问题
2. 原理：分节讲透
3. 工程实现：代码/参数/协议怎么用
4. 常见误区
5. 习题 / 面试问答
```

## 2. 术语表格式

统一四列：

| 术语 | 英文 | 一句话定义 | 单位/量级 |
|---|---|---|---|
| 声压级 | SPL | 声压相对 20 µPa 的对数表示 | dB SPL，0–120 |

分类建议：

1. **物理量**（客观可测）：声压、频率、码率、带宽
2. **主观量**（人耳/人眼感知）：响度、phon、sone、画质
3. **分析工具**（模型/刻度）：Bark、ERB、临界频带、JND
4. **工程实现**（算法/工具）：MDCT、TNS、SMR、GOP

## 3. 写作规则

1. **先定义，后使用**：正文第一次出现术语时，要么已在术语表，要么当场用括号解释。
2. **首次出现给英文**：`心理声学（Psychoacoustics）`。
3. **公式配符号表**：每个符号是什么、单位是什么、取值范围。
4. **数值给前提**：写「约」「典型」「在 XX 条件下」，避免绝对化。
5. **类比只辅助**：类比放在定义之后，不能替代定义。
6. **不循环定义**：不能用「响度就是听起来多响」这种同义反复。
7. **区分客观与主观**：dB SPL 是客观量，phon/sone 是主观量，不能混用。

## 4. 自检清单

- [ ] 开头有术语表
- [ ] 每个缩写首次出现有全称
- [ ] 公式的符号都有说明
- [ ] 数值有前提条件
- [ ] 主观量与客观量没有混用
- [ ] 结尾有习题或面试问法
